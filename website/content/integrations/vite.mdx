`unplugin-saykit` is the SayKit plugin for every bundler [unplugin](https://github.com/unjs/unplugin) supports. Only the import path changes between them.

## Install

```sh
pnpm add -D unplugin-saykit @saykit/config @saykit/format-po @saykit/transform-js @saykit/transform-jsx
```

The plugin takes no options; it reads `saykit.config.ts`.

## What it does

It rewrites the macros in every file a bucket includes, so `` say`Hello, ${name}!` `` becomes `say.call({ id: '…', _name: name })`. That is all. Catalogues are compiled by [`saykit compile`](/reference/cli#saykit-compile) into ordinary `{locale}.js` modules, which the bundler loads, splits and hot-reloads like any other.

<Callout type="info">
  Run `saykit compile` before anything that imports those modules, usually as `predev` and
  `prebuild` scripts. Keep `saykit extract --watch` running in development to recompile when a
  translation changes.
</Callout>

## Notes

- **Ordering.** The plugin runs with `enforce: 'pre'`, so it sees macros before other transforms. A plugin that lowers tagged templates must run after it.
- **Vite** works beside `@vitejs/plugin-react` and **TanStack Start**. Vitest picks the plugin up from `vite.config.ts`, which the macros need.
- **Next.js** should use [`babel-plugin-saykit`](/integrations/babel) instead.
